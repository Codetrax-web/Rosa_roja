# 🌹 Rosa Roja

"Algunas flores no necesitan palabras."
Este proyecto fue creado como una experiencia visual inspirada en el simbolismo de las flores amarillas: amistad, alegría, esperanza y momentos especiales compartidos.
Cada animación busca transmitir la sensación de recibir un ramo de flores que nunca se marchita.
